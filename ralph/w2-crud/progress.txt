# Ralph progress log — Atelier — August 6th updates — W2 CRUD completion

## Codebase Patterns

General, reusable findings only. A Ralph iteration reads this block FIRST, before anything else.
Story-specific detail belongs in the per-story entries below, not here.

- **This branch does not contain W1.** `aug6/w2-crud` is cut from `main` plus the Ralph scaffold
  (`38868e1`), not from `august-6th-updates`. So none of W1's deliverables exist here:
  `atelier-api/src/lifecycle/` is absent entirely, and `atelier-crm/src/admin/` holds only
  `drafts.js`, `orderFlow.js`, `parts.jsx`, `stock.js` — no `list.js`, `useAdminList.js`,
  `Pagination.jsx`, `ConfirmDialog.jsx`, `deleteFlow.js`, `useCrudScreen.js`, and `src/lib/api.js`
  has no `apiDelete`. Verify with a `ls`/grep before assuming otherwise; do not author those files,
  they belong to W1.
- **Which W2 stories that gates.** Every story whose deliverable is a DELETE (US-001..004, and the
  delete half of US-007/US-008) needs `deleteOrExplain`/`replyDelete` + a registry entry; every CRM
  story (US-009..012) needs `useCrudScreen`/`Pagination`/`apiDelete`. The read-only stories
  (US-005 admin reads by id, US-006 colourway list/detail) have **no** W1 dependency and are
  implementable on this branch today.
- Story pick order is by `priority`, so a blocked low-priority story does not stop the loop — it is
  marked BLOCKED and the next iteration moves down the list.
- **A story's file footprint is the ROUTE file plus the DOMAIN module it calls.** `src/routes/*` is
  thin by house rule, so the logic always lands in `src/<domain>/`. Owning `admin-price-lists.js`
  the route says nothing about `src/pricing/admin-price-lists.js` the module. Check both against the
  MAY-touch list before starting, and check each entity separately when a story names two.
- **Re-verify a shared blocker; do not inherit it from this log.** A previous entry recording
  "dependency absent" is a statement about the branch at that moment, and another workstream can
  land it in between. Two commands settle it in seconds — `ls atelier-api/src` for `lifecycle/`,
  `ls atelier-crm/src/admin` for the CRUD kit — and they are cheaper than either blocking a story
  that has become implementable or building on one that has not arrived.
